[ ] Power button (FINAL plan 2026-07-03: DIY soft-latch, ~5 ILS, no PCB —
    6 components on a 2x3cm perfboard scrap; replaces Pololu & slide-switch)
    - Circuit: P-MOSFET Q1 in series TP4056 OUT+ -> MT3608 VIN
      (NDP6020P TO-220, or DMG3415U/SI2333 SOT-23 on DIP adapter;
      low Rds at Vgs -3V, >=2A). R1 100k gate->source.
      Button (momentary, to GND) tees to:
        (a) Q1 gate via 1N4148 (anode at gate) = hardware power-on while held
        (b) GPIO17 (internal pull-up)         = software press sensing
      Q2 2N7000: drain->Q1 gate, source->GND, gate <- 10k <- GPIO4 (hold)
    - config.txt:  gpio=4=op,dh                      (firmware hold at ~2s;
                                                      this IS long-press-to-on)
                   dtoverlay=gpio-poweroff,gpiopin=4,active_low
                                                     (drops hold AFTER clean
                                                      shutdown -> power cut)
    - Behavior: hold ~2-3s = power on; button can NOT hard-cut while running;
      short press = screen toggle, long press ~2s = systemctl poweroff ->
      self power-cut. True off = zero drain.
    - Software: GPIO17 listener thread in the app (gpiozero/libgpiod, guarded
      import so dev machines no-op); reuse backlight.set_on + screen-off state
    - Enclosure: only a button hole needed (no slide-switch cutout)
    - Do the OS hardening pack first anyway (general hard-cut insurance)
